# Architecture Review Rubric

Score each item: PASS / CONCERN / FAIL / N/A.

- Problem and architecture are aligned.
- Boundaries and responsibilities are explicit.
- Existing repository patterns were considered.
- Data ownership is unambiguous.
- Interfaces/contracts are explicit.

- Security boundaries are defined.
- Identity and permissions follow least privilege.
- Observability is designed, not deferred.
- Deployment and rollback are feasible.
- Scale assumptions are stated.
- Migration/backward compatibility is addressed.
- Complexity is proportional to requirements.
- Alternatives were considered.
- Architecture is testable.
- AI/agent autonomy boundaries are explicit when relevant.
