# Security Review Rubric

- Threat boundaries identified.
- Authentication is appropriate.
- Authorization is explicit and least-privilege.
- Secrets are isolated.
- Sensitive data is classified and protected.
- Inputs are validated.
- Outputs are safely encoded/handled.
- Injection risks are addressed.
- External content is treated as untrusted.
- Agent tools are allow-listed.
- Destructive actions require explicit controls.
- Audit logs are sufficient.
- Dependency/supply-chain risk is considered.
- Failure/retry behavior cannot amplify harm.
- Rate/financial/operational limits exist where needed.
- Kill switch / disable path exists for autonomous systems.
