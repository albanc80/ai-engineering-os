# Release Readiness Rubric

- Acceptance criteria passed.
- Required automated tests passed.
- Regression tests passed.
- Blocker/high review findings resolved or explicitly accepted.
- Migration is validated.
- Rollback is documented and feasible.
- Configuration is validated.
- Secrets and credentials are validated.
- Monitoring/logging/alerts are ready.
- Operational ownership is clear.
- Runbook exists when needed.
- Capacity/performance risks are acceptable.
- Security review is complete when required.
- User/business communication is prepared when needed.
- Post-release validation steps are defined.
